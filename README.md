# Luke’s reading list

A quiet, cover-first gallery of books read. One search box filters title and author instantly, including accent-insensitive and mixed title/author searches. Responsive, keyboard accessible, and entirely static. No dependencies, build, API keys, tracking, or runtime network requests are needed. Covers are downloaded into the repository.

## View

Open `index.html` directly, or serve this directory with `python3 -m http.server 8000` and visit http://localhost:8000.

## GitHub Pages

1. Put this directory's contents at the root of your GitHub repo and push to `main`.
2. In the repo's **Settings → Pages → Build and deployment**, select **GitHub Actions**.
3. The included workflow deploys on pushes to `main` and can be run manually in Actions. If your default branch differs, edit `.github/workflows/pages.yml`.

All asset paths are relative, so both `username.github.io` and `username.github.io/repo-name/` work. Live site: https://lukestein.com/books-list/.

## Refresh from the reading list

Requires Python 3.10+ and internet access, with no packages to install:

```sh
python3 scripts/refresh.py 'https://p.fsnot.es/xq3vxou4cf/' --covers
```

Use a new FSNotes URL or a saved HTML file in place of that URL. The importer expects a table with columns number, title, author, and optional summary. It preserves source order and all rows, including repeated readings. Stable IDs use title and author. Existing cover choices are retained, and only new/missing covers are requested. A failed page fetch or unrecognized table leaves existing data untouched. Missing images get a decorative text jacket; these are placeholders, not actual covers.

The script writes `data/books.json` (editable canonical records) and `data/books.js` (the same data as a browser script so the page also works from disk). After manual JSON edits, run:

```sh
python3 scripts/export.py
```

Commit changed data and covers, then push. To update via an agent, ask it:

> Refresh the reading room from UPDATED_URL using scripts/refresh.py with --covers. Preserve the existing design and cover overrides. Review unmatched covers and changes in book count, then commit the data and images.

There is no automatic refresh on page load; changes are reviewed and checked into Git.

## Covers and corrections

The importer searches Open Library by title and author and downloads medium JPEG covers. It records the original image URL and matched work link with each successful result. Covers may represent a different edition from the one read, and automatic matches can need review. To correct one, place a JPEG in `assets/covers/`, change that book's `cover` path and provenance fields in `data/books.json`, then export. Local cover overrides survive refreshes. To retry a match, remove its cover fields before refreshing.

Book cover artwork remains the property of its respective rights holders; downloading an image does not transfer rights. Metadata is imported from the owner’s FSNotes reading list. Image source: [Open Library](https://openlibrary.org/) and its [Covers API](https://openlibrary.org/dev/docs/api/covers).

## Files

- `index.html`, `style.css`, `app.js`: page, styling, filter behavior.
- `data/books.json`, `data/books.js`: book records and browser data.
- `assets/covers/`: local cover images.
- `scripts/refresh.py`: repeatable import and cover downloads.
- `scripts/export.py`: regenerate browser data after manual edits.
- `.github/workflows/pages.yml`: GitHub Pages deployment.

Design copy, colors, and title can be changed directly in HTML and CSS.

## Presentation conventions

The gallery displays entries in reverse input order, newest first. Book numbers reflect their original list positions (1–441 for the initial import) and stay fixed during searches. `[re-read]` is stored as `reread: true`, with the original string in `sourceTitle`; the gallery shows an asterisk linked to the footer explanation. IDs remain based on the original source title so cover overrides survive another import.

The header’s month/year comes from `window.LIBRARY_META`, generated by `scripts/export.py` using America/New_York time. The Pages workflow runs this export on every deployment. The private import URL and import metadata are not included in the deployed assets or linked from the page.

The re-read note appears only when a visible result is a re-read. Each author name is a separate search button. At export, author credits are split on ampersands, “and”, commas, and semicolons, keeping suffixes such as “Jr.” attached. Original `author` strings stay unchanged in `data/books.json`. For ambiguous credits (such as a single author written “Surname, Given name” or a group name containing “and”), set an explicit `authors` array on that record, then export; refreshes preserve this override.

Clicking an author from the full gallery remembers that book’s position. Clearing the filter returns to it and restores focus to the author button, including when using Escape or clearing from the no-results message. Further author clicks within filtered results keep the original return position.

### Finding better covers

`python3 scripts/improve-covers.py --output /tmp/cover-candidates.json` retries missing images with shorter titles and normalized author names. It downloads candidates but does not change the book records; inspect each candidate and merge approved fields into `data/books.json`, then run `scripts/export.py`. For plain bindings or title-page scans, inspect alternate covers on the matching Open Library work. Google Books’ public ViewAPI can return thumbnails for verified ISBNs even when the volume-search API has no available quota. Publisher pages are another useful source; the cover for *The Curve of Binding Energy* comes directly from Macmillan. Keep `coverSource` and `coverWork` for all replacements.

The October 2026 cover review added 24 missing covers (including re-read reuse) and replaced six generic bindings/title pages with illustrated covers. Some gaps remain; automatic candidates require visual review.

A subsequent Calibre library review supplied 13 more missing covers, leaving 29 of the 441 entries without artwork. These local copies record the Calibre book ID in `coverSource` and the library record UUID in `coverWork`; the original upstream image sources are unknown. Existing cover choices and reading-list metadata were preserved. The source list subsequently corrected Katherine Boo’s title to *Behind the Beautiful Forevers*; its Calibre cover was retained across the title and record-ID change.
